# SecurePass Analyzer

A responsive password-strength checker built using HTML, CSS and vanilla JavaScript.

## Features
- Live score from 0 to 100
- Weak, Medium and Strong feedback
- Circular score indicator
- Show/hide password button
- Five password-quality checks
- Personalized improvement tips

## How to run
Open `index.html` in any modern web browser. No installation is needed.

## Privacy
All checks run locally in the browser. The password is not uploaded, stored or transmitted. Use a sample password when demonstrating the project.

## Built with
HTML5 · CSS3 · JavaScript
