Problem Statement
Write a Python program to calculate the factorial of a given positive integer.

The factorial of a number n is the product of all positive integers from 1 to n.

Formula
n! = n × (n-1) × (n-2) × ... × 1

For example:

5! = 5 × 4 × 3 × 2 × 1 = 120

Input
The program takes a single positive integer n as input.

Example Input
5 Output

Print the factorial of the given number.

Example Output 120 
Another Example Input 6 Output 720 
Technologies Used Python 3 
Instructions to Run
Make sure Python 3 is installed on your system. Open the terminal or command prompt. Navigate to the folder containing factorial.py. Run the following command: python factorial.py Enter a positive integer when prompted. The program will display the factorial of the given number. 
Logic

The program initializes the factorial value as 1 and uses a for loop to multiply each number from 1 to n.

For input 5:

1 × 2 × 3 × 4 × 5 = 120

Therefore, the output is:

120
