
# ✨ Motivational To-Do List

A modern and interactive To-Do List web application designed to help users organize daily activities, track progress, and stay motivated.

## 📌 About the Project

The Motivational To-Do List helps users manage their daily tasks through an interactive calendar and a productivity dashboard. Its colorful gradient interface makes task management simple and enjoyable.

## 🚀 Features

- 📅 Interactive monthly calendar
- ✅ Add, complete, and delete tasks
- 🎯 Set task priorities: High, Medium, and Low
- 📊 Track daily progress and completion percentage
- 📈 View total completed tasks and success rate
- 🔥 Track consecutive days with completed tasks
- 🔍 Filter tasks by All, Pending, and Completed
- 🌙 Switch between light and dark themes
- 💾 Save tasks using browser Local Storage
- 📱 Responsive layout for different screen sizes
- 💡 Motivational quotes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or run it using the Live Server extension.
4. Add tasks, select dates, set priorities, and track your progress.

## 💾 Data Storage

Tasks are stored in the browser's Local Storage. Data remains available in the same browser unless its stored site data is cleared. Local Storage does not automatically synchronize tasks across different devices.

## 🎓 Project Purpose

This project demonstrates front-end web development concepts, including DOM manipulation, event handling, date-based task management, responsive CSS layouts, and browser storage.
